# Games Backlog

A website where you can add games that you want to play, currently play, finished or dropped.

[Live Link](https://questlog-api-xi.vercel.app/)

## Run project locally

```bash
git clone [https://github.com/Prxjec-t/Questlog-API]
cd portfolio
npm i || npm install
npm run dev
```
